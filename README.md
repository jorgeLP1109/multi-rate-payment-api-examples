# Multi-Rate Exchange & Payment Validation API - Code Examples

Este repositorio contiene ejemplos prácticos para consumir la **Payment & Exchange Rate API** en Node.js, Python y PHP.

## 🚀 Características de la API

- **Tasas en Tiempo Real**: BCV (Venezuela), Banxico (México), SFC (Colombia) y Binance P2P (Cripto/USDT).
- **Validación de Pagos**: Verificación unificada de transacciones con prevención de duplicados.
- **Respuesta Ultrarrápida**: Infraestructura Serverless optimizada con caché distribuido.
